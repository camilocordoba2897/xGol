⚡ Elige el partido
Los datos se traen solos desde la API. Escoge una liga y toca un partido: se cargan los últimos 15 encuentros de cada equipo y se calcula la predicción.
Qué cubre el modo automático: ganador, goles, ambos anotan, marcador y mercados de primer tiempo. Córners, tarjetas, tiros y jugadores necesitan datos que la API actual no entrega — para esos, usa el modo manual de abajo.
Modo manual · cargar CSV y biblioteca de equipos

¿Cómo funciona? Carga el historial de partidos de cada equipo en formato CSV y el sistema calcula automáticamente las probabilidades del enfrentamiento. Cuantos más partidos incluyas, más precisa será la predicción. Puedes descargar un CSV de ejemplo para ver el formato correcto.
