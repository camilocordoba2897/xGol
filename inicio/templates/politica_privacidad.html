{% translate "1. Responsable del tratamiento" %}

{% blocktranslate trimmed %}xGol es el responsable del tratamiento de los datos personales recolectados a través de la Plataforma, de acuerdo con la Ley 1581 de 2012 y el Decreto 1377 de 2013 de la República de Colombia (régimen de protección de datos personales / Habeas Data).{% endblocktranslate %}

{% translate "2. Datos que recolectamos" %}

{% blocktranslate trimmed %}Recolectamos: (a) datos de registro (nombre, usuario, correo electrónico, contraseña cifrada, cédula y fecha de nacimiento para verificar la mayoría de edad) y, si la subes, tu foto de perfil; (b) datos de suscripción y facturación necesarios para procesar el pago; (c) los partidos que consultas en el Analizador y la evaluación de esos pronósticos cuando se juegan; (d) datos técnicos básicos de uso (accesos, IP, fecha) con fines de seguridad.{% endblocktranslate %}

{% translate "3. Finalidad del tratamiento" %}

{% blocktranslate trimmed %}Usamos tus datos para: crear y administrar tu cuenta, procesar tu suscripción, medir qué tan bien acierta el motor de predicción, mejorar el servicio, y comunicarnos contigo sobre tu cuenta (ej. vencimiento de suscripción).{% endblocktranslate %}

{% translate "4. Con quién compartimos tus datos" %}

{% blocktranslate trimmed %}No vendemos ni compartimos tus datos personales con terceros con fines comerciales. Solo se comparten datos de pago con la pasarela de procesamiento que gestiona tu suscripción, en la medida necesaria para completar la transacción.{% endblocktranslate %}

{% translate "5. Almacenamiento y seguridad" %}

{% blocktranslate trimmed %}Tus datos se almacenan en una base de datos con acceso restringido. Las contraseñas se guardan cifradas y nunca se almacenan en texto plano. Aplicamos medidas razonables de seguridad, aunque ningún sistema es 100% infalible.{% endblocktranslate %}
